    Accepted formats
    • Moves, one per line: 4 3, 4 -> 3 / 5+, Anna: 4 -> 3, Anna Smith 4 3 5, or tab-separated from a spreadsheet. # starts a comment.
    • Groups, one per line: id min current max [name] or id size [name].
    • main.cpp input is exactly what group_mover reads: the seed, the groups, a blank line, the moves, a blank line.
